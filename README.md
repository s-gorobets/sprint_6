# 🛵 Проект: Автоматизация тестирования сайта "Самокат"

Этот проект направлен на автоматизацию тестирования сайта [Самокат](https://qa-scooter.praktikum-services.ru)  — сервиса заказа самокатов. Основная задача — проверить корректность работы формы заказа, включая заполнение данных пользователя, выбор параметров аренды и оформление заказа.

---

## 📋 Как тестировался

### 🧪 Подходы к тестированию:
- **Page Object**  
  Созданы классы для каждой страницы (например, `OrderPage`), где собраны методы для взаимодействия с элементами (заполнение полей, клики, выбор из списков).
- **Параметризация**  
  Тесты запускаются с разными наборами данных (имена, адреса, даты аренды), что позволяет проверить разные сценарии.
- **Проверки**  
  После оформления заказа утверждается, что появилось сообщение `"Заказ оформлен"`.

### 🔁 Этапы тестирования:
1. **Первая страница заказа**:
   - Заполнение полей: `Имя`, `Фамилия`, `Адрес`, `Телефон`.
   - Выбор станции метро.
   - Переход на вторую страницу.

2. **Вторая страница заказа**:
   - Указание даты аренды, выбор срока (например, "двое суток").
   - Выбор цвета самоката (черный), добавление комментария для курьера.
   - Подтверждение заказа.

### 🔍 Работа с элементами:
- Использовались локаторы (CSS-селекторы, XPath) для поиска элементов на странице.
- Добавлены явные ожидания (`WebDriverWait`) для стабильности тестов при работе с динамическими элементами (например, выпадающими списками).

## 📊 Результаты

Тесты автоматически проверяют, что:
- Все поля формы заполняются корректно.
- Выпадающие списки и кнопки работают.
